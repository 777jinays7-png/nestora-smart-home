SMART HOME NETWORK - LOCAL DEMO

Requirements:
- Windows 10/11
- Python 3.10+ installed and added to PATH

Run:
1. Extract the ZIP to a normal folder, e.g. Desktop\smart_home_network
2. Open that folder in File Explorer.
3. Double-click run_windows.bat
4. Wait for Flask to start, then open http://127.0.0.1:5000 in your browser.
5. Keep the black terminal window open while using the dashboard.
6. Press Ctrl+C in the terminal to stop the server.

Alternative using Command Prompt:
  cd Desktop\smart_home_network
  python -m pip install -r requirements.txt
  python app.py

This is a local dashboard prototype with simulated device states. It does not control physical IoT devices or Cisco Packet Tracer directly. The displayed network status and device actions are for a local demonstration. Replace demo results with real evidence in the project submission.
